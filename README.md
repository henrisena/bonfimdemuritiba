# Festas Muritibanas

**Cultura, identidade e memória**

Site-laboratório do PIBID História para pesquisa e construção colaborativa de um acervo digital sobre festas, memórias, objetos, fotografias e lugares de Muritiba (Bahia).

## Estrutura inicial

- Festas
- Memórias
- Objetos
- Álbum
- Nossa pesquisa
- Colabore
- Sobre

Esta é a primeira versão do protótipo. O conteúdo será ampliado a partir da pesquisa realizada pelos estudantes e bolsistas, com identificação, contextualização e curadoria das fontes antes da publicação.
